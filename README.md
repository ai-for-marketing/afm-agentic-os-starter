# AFM Agentic OS — Starter (sawdust-stub, v0.1)

The minimal, portable taste of the **AFM Agentic OS** — the methodology + the self-looping
commander goal that turns a vague product idea into a shipped, verified, valuable reality
without you as the manual bottleneck.

This is a **starter, not the working harness.** It transfers the *recipe*, not the *kitchen*.
The full OS (272 skills, 6 conduct loops, watchdog, the vault, GridOS) is the integrated
moat — see the bottom of this file for access.

---

## What you get

| File | What it is |
|------|------------|
| `AFM-BUILD-OS.md` | The method: North Star → Blueprint → Build → QA → **Value → UX** → Harden. Why things stall at 90%, and the enforced-contract blueprint + owner-gate manifest that fixes it. |
| `master-goal-prompt.txt` | A self-looping `/goal` prompt. Paste it into Claude Code / Codex / Gemini in your project; it self-localises, audits reality vs the North Star, runs safe work orders, verifies real outcomes, and loops to a terminal state. |
| `install.sh` | One-command install. Copies the above into `~/afm-agentic-os/` and prints the next step. |

## Install

```bash
bash install.sh
```

Then open `~/afm-agentic-os/master-goal-prompt.txt`, copy the whole `/goal ...` block, and
paste it into an AI CLI session inside the project you want to build. The commander loop
self-localises to that project and runs.

## What this is NOT (honest scope)

- **Not the working harness.** No skills pack, no conduct loops, no watchdog, no vault, no
  GridOS. Those are the integrated system the author runs in production across 6 live projects.
- **Not a wizard.** It won't auto-discover your stack or seed your memory. You read the
  method, run the /goal, and the loop does the rest inside *your* environment.
- **v0.1.** The method + loop are battle-tested (6 projects, 89+ conduct commits); the
  *packaging* of this starter is new. Expect to adapt paths to your setup.
